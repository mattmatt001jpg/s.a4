Module 7: Euler Diagrams

Arguments & Validity

1. Ano ang logical argument?

Ang logical argument ay binubuo ng mga premises at isang conclusion.

  • Premises — mga palagay, rules, facts, o observations na pinanggagalingan ng reasoning.
  • Conclusion — ang resultang gustong patunayan mula sa premises. Madalas itong may simbolong ∴ na ibig sabihin ay “therefore.”
Halimbawa: All men are mortal. Jay-ar is a man. ∴ Jay-ar is mortal.

2. Valid at invalid arguments

Valid ang argument kapag ang pagiging true ng lahat ng premises ay sapilitang nagpapaging true sa conclusion. Invalid naman kapag may posibleng diagram na true ang premises pero false ang conclusion. Ang invalid reasoning ay tinatawag ding fallacy.

Mabilis na test: Hindi sapat na “mukhang tama.” Dapat walang kahit isang possible arrangement na kokontra sa conclusion.

3. Apat na basic statement patterns

All S are P Lahat ng S ay nasa loob ng P.
No S are P Magkahiwalay; walang overlap.
Some S are P May x sa overlap ng S at P.
Some S are not P May x sa S-only region.

4. Paano gamitin ang Euler diagram sa validity?

  1. Iguhit ang diagram para sa unang premise.
  2. Idagdag ang ikalawang premise sa parehong diagram.
  3. Tingnan ang lahat ng possible diagrams. Valid lamang kung lahat ay nagpapakita ng conclusion.

Module 8: Boolean Algebra & Logic Circuits

Gates, Laws & Tables

1. Ano ang Boolean Algebra?

Ito ang mathematics na ginagamit para mag-analyze at mag-simplify ng digital gates at circuits. Dalawa lang ang values ng Boolean variable: 0 = false at 1 = true.

  • Variable — simbolo para sa logical quantity, gaya ng A, B, x, at y.
  • Complement — kabaligtaran ng variable; isinusulat bilang A′ o may bar sa ibabaw.
  • Literal — isang variable o complement nito; halimbawa A at A′.
  • Boolean expression — kombinasyon ng variables, 0, 1, at operations.
  • Boolean function — mapping mula sa Boolean inputs papunta sa Boolean output.
  • Truth table — listahan ng lahat ng input combinations at katumbas na output.
  • Logic diagram — drawing ng gates, inputs, connections, at output ng circuit.
Bakit nagse-simplify? Para mas madaling maintindihan ang function at mabawasan ang gates at inputs na kailangan ng circuit.

2. Basic at derived logic gates

AND • AB

Output = 1 lamang kung lahat ng inputs ay 1.

OR • A + B

Output = 1 kung may kahit isang input na 1.

NOT • A′

Binabaligtad ang input: 0→1 at 1→0.

NAND • (AB)′

Kabaligtaran ng AND; 0 lamang kapag parehong 1.

NOR • (A+B)′

Kabaligtaran ng OR; 1 lamang kapag parehong 0.

XOR • A ⊕ B

Output = 1 kapag magkaiba ang dalawang inputs.

3. Tatlong pangunahing Boolean operations

Ang sum term ay OR lamang at magiging 0 lang kapag lahat ng literals ay 0. Ang product term ay AND lamang at magiging 1 lang kapag lahat ng literals ay 1.

5. Function minimization

Gamitin ang laws para paikliin ang expression. Halimbawa:

  • A(A+B) = A — Absorption Law.
  • AB + AB′ = A(B+B′) = A(1) = A.
  • (A+B)(A+B′) = A + BB′ = A+0 = A.
  • AB + AB′C = A(B+B′C) = A(B+C) = AB+AC.

6. Boolean expression mula sa logic circuit

Magsimula sa left-most inputs at gumalaw papunta sa final output. Isulat muna ang expression ng bawat gate.

Example: Kung C at D ay pumasok sa AND, makukuha ang CD. Kapag in-OR ito kay B, magiging B+CD. Kapag in-AND kay A, final output ay A(B+CD).

7. Expression, circuit, at truth table

Para sa F(x,y,z)=x+y′z:

  1. I-NOT ang y para makuha ang y′.
  2. I-AND ang y′ at z.
  3. I-OR ang result kay x.
  4. Sa truth table, ilista ang 8 combinations dahil 2³ = 8.
